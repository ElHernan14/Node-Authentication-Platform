# Authentication System

Aplicación desarrollada con Node.js para implementar un sistema completo de autenticación de usuarios.

## Funcionalidades

- Registro
- Inicio de sesión
- JWT
- Hash de contraseñas
- Autenticación protegida

## Tecnologías

- Node.js
- Express
- MySQL
- JWT
- bcrypt
- EJS

## Objetivo

Proyecto orientado a practicar autenticación segura y manejo de sesiones utilizando tecnologías del ecosistema Node.js.
